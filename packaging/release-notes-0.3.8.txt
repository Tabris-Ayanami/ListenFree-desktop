ListenFree 0.3.8 · Windows x64

- 系统性修复 LX 自定义音源的运行环境：使用固定版本的 core-js 与 Buffer 浏览器实现，补齐 URL、Base64 和二进制字节行为。
- 统一脚本回调与 Promise 微任务收尾，支持异步初始化；初始化与解析采用一致期限，取消和超时会释放所属网络请求及定时器。
- 修复 HTTP 错误正文、请求编码、加密参数与二进制数据兼容，保留音源返回的具体错误；初始化后的普通后台异常不再误判整个音源失效。
- 修复同名音源文件覆盖，补齐 QQ、酷狗等平台的歌曲身份与音质字段。
- 修复 Windows 普通窗口圆角外出现白色区域，以及侧栏透明被玻璃背景覆盖的问题；窗口区域随缩放、最大化、全屏和窗口重建同步。
- 保留 0.3.7 无尽模式等已有功能。

音源服务停服、证书错误、权限或限流仍可能导致部分音源不可用；不会跳过 TLS 校验。窗口修复已在本机两档缩放完成画面验证，Windows 11 24H2 实机尚未验证。

本次发行附件仅为 Setup.exe，请从 GitHub Release 下载后安装升级；未附应用内更新所需的 appcast.xml。安装包不含个人曲库、账号凭据、缓存或用户音源脚本。
